Things i learned:
- to override default switch behavior, rule has to use all states of the switch simultaneously with on (link to docu)
- power state cannot be used as a variable within the rule -> use temp var
- there are three rule (1,2,3) storage spaces each On is a rule, so you cant delete those rules, just the space inside them

Tasmota Rules
```
Rule1
  ON Switch1#State DO IF ((Time>=Sunset) OR (Time<630)) IF (%value%==1) IF ((Var2==0) AND (Var1==0)) Power1 ON; Channel1 35; Var1 1 ENDIF; RuleTimer1 0 ELSE IF (Var1==1) RuleTimer1 10 ENDIF ENDIF ENDIF ENDON
  ON Rules#Timer=1 DO IF (Var1==1) Power1 OFF ENDIF ENDON
  ON Power1#State=0 DO Backlog Var1 0; Var2 0 ENDON
  ON Power1#State=1 DO Var2 1 ENDON

Rule2 
  ON Switch2#State DO IF ((Time>=Sunset) OR (Time<630)) IF (%value%==1) IF ((Var4==0) AND (Var3==0)) Power2 ON; Channel2 35; Var3 1 ENDIF; RuleTimer2 0 ELSE IF (Var3==1) RuleTimer2 10 ENDIF ENDIF ENDIF ENDON
  ON Rules#Timer=2 DO IF (Var3==1) Power2 OFF ENDIF ENDON
  ON Power2#State=0 DO Backlog Var3 0; Var4 0 ENDON
  ON Power2#State=1 DO Var4 1 ENDON
```

This has to be changed for each switch. I have two switches 1 & 2, hence the two indices. See the comment above!

```
SwitchMode1 1
SwitchMode2 1
```

https://tasmota.github.io/docs/Commands/#setoptions

```
SetOption0 0 # reset power state after a reboot. so lights will be off after a restart if they were one before. this is important to avoid bug in which lights stay permanently on unless motion sensor fires again
SetOption65 1 # disable possibility to reset device via power cycling (turning this off by setting this to 1 is not a typo)
SetOption57 0 # disable Wi-Fi network re-scan every 44 minutes to find better signal
```
